⚙️ Configurar Firebase

Cole os dados do seu projeto Firebase para conectar o banco de dados compartilhado.

1 Acesse console.firebase.google.com e abra seu projeto
2 Menu lateral → Firestore Database → Criar banco → Modo de teste
3 Engrenagem ⚙️ → Configurações do projeto → Seus apps → copie os dados
